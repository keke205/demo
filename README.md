# 分期明白账｜轻量级静态交互原型

这是项目计划书的辅助材料，不是工商银行产品，也没有连接真实银行账户。全部交互在本地浏览器完成，无后台、数据库、登录、上传或数据保存。请只用演示/模拟数字。

## 如何打开

1. 双击本目录的 `index.html`，或在浏览器中选择“打开文件”。不需要安装依赖或启动服务器。
2. 点击“开始体验”，选择电脑、手机或平板案例；也可修改购买价、期数与总费用。修改预设案例后，页面会改标为“自定义模拟案例”。
3. 确认方案后，查看并修改逐月模拟收入、固定支出和特殊支出。
4. 点击“查看两种支付方式”，阅读费用卡片、两条余额线、最低余额月份与解释；可在“指定月份对比”里直接查看两条路径的余额差。点击“修改收支”可重新计算。
5. 收支表支持把首月收入或固定支出批量沿用、清空特殊支出和撤销尚未计算的本页修改。
6. `baseline.html` 是小样本任务测试的**原始信息对照页**，刻意不显示计算结果。可用 `baseline.html?case=computer`、`?case=phone`、`?case=tablet` 指定案例；原型也支持 `index.html?case=...`。

建议截图顺序：首页 → 分期确认 → 收支输入 → 结果页。截图前不要输入任何参与者真实财务资料，图下注明“静态交互原型，全部数字为演示/模拟数据”。

## 页面与信息结构

| 页面/步骤 | 主要内容 | 作用 |
|---|---|---|
| 首页 | 项目定位、三个要回答的问题、演示声明 | 让评委理解它不是普通分期计算器 |
| 确认分期 | 三个预设案例、可编辑金额/期数/总费用、来源边界 | 区分官网公开基准参数与自设模拟数字 |
| 填写未来收支 | 期初余额、逐月收入、固定支出、特殊支出 | 把本次分期置入未来月份 |
| 查看对比 | 总支付、额外费用、每期款、两条现金流、最低月份、解释 | 展示核心增量 |
| 原始信息对照页 | 同样的案例原始条件，无计算答案 | 供10—20人任务测试的对照条件使用 |

## 计算范围

- 当前假设一次性购买价等于分期本金，首期从第1个月开始，正常履约，分期本金和费用均摊。不能除尽的分位放在首期。
- 每月月末余额 = 上月月末余额 + 本月收入 − 本月固定支出 − 本月特殊支出 − 本月该方案付款。
- 两条路径使用同一份非本次购买的收支；最终余额差额等于模拟分期费用的负值。
- 不覆盖商户折扣、一次性收取费用、违约、提前还款和个性化报价。费率不明时请先填入明确的总费用；不要把页面数字用于真实金融决定。
- SVG图表由本地JavaScript生成，没有第三方图表库或网络调用。

## 测试方式与状态

项目计划书仍是核心成果。原型用于说明交互和辅助小样本任务测试；真人测试尚未开展。建议A主持，B匿名记录，C复核案例答案并处理页面问题。对照条件使用 `baseline.html`，原型条件使用 `index.html` 的另一案例，交错案例与顺序。记录五题正确与否、用时和两条极短反馈，不索要银行卡、真实账单、收入或负债。

计算测试脚本：`tests/test_logic.js`（需要Node.js）。目前已验证三个预设案例、分位分摊和无效期数。页面需要团队在本机实际浏览器核对布局、可读性与截图；不把程序测试等同于真人体验或银行验收。
